### 🔬 ML Attacks on Physical Unclonable Functions
> *MSc Dissertation — Queen's University Belfast, 2023*

Physical Unclonable Functions are hardware-level authentication mechanisms — and I broke them with machine learning. Used **Generative Adversarial Networks (GANs)** to synthesise realistic PUF challenge-response pairs, then trained ML models to predict PUF behaviour and evaluate attack success rates.

`Python` `GANs` `Machine Learning` `Cryptography` `Hardware Security`

**Key outcome:** Demonstrated measurable PUF vulnerability and proposed concrete countermeasures against ML-based attacks.

---

### 🍯 Honey Encryption — Brute-Force Resistant Security
> *Queen's University Belfast, 2023*

Researched and implemented a conceptual framework for **Honey Encryption** — a technique that generates plausible-looking fake plaintext when an attacker decrypts with the wrong password, making brute-force attacks effectively blind. Proposed a developer-facing API for real-world integration.

`Python` `Encryption` `DTE` `API Design` `Cloud Security`

**Key outcome:** Designed an API framework applicable to internet banking, cloud accounts, and biometric systems.

---

### 🔍 NTFS Digital Forensics — File Recovery on Windows 10
> *Queen's University Belfast, 2023*

Practical forensic investigation into deleted file recovery on Windows 10 NTFS using MFT analysis, slack space examination, disk imaging, and CLI recovery tools. Directly applicable to cybercrime investigation and incident response.

`Windows Forensics` `MFT Analysis` `Disk Imaging` `CLI Tools` `NTFS`

**Key outcome:** Documented a reproducible methodology for evidence preservation and breach analysis.
